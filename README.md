# k8s-kafka-gitops-lab

Local Kubernetes platform lab focused on Kafka-based integrations and GitOps workflows.

This project is a design-first, minimal event-driven platform built for learning,
experimentation and architectural exploration.

The goal is to:

- explore Kafka on Kubernetes
- apply GitOps principles
- experiment with delivery semantics (at-least-once, idempotency, DLQ)
- keep everything runnable locally
